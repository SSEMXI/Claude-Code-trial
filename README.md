# Claude-Code-trial

A test repository for practicing GitHub workflows with Claude Code.

## What is this?

This repo is used to learn the end-to-end GitHub workflow:
- Creating branches
- Making changes
- Opening pull requests
- Reviewing and merging

## Getting Started

Clone the repo and start experimenting:

```bash
git clone https://github.com/SSEMXI/Claude-Code-trial.git
cd Claude-Code-trial
```
